# Independent Product & R&D Portfolio

I build practical software, privacy tools and affordable robotics with AI-assisted development.

**Operating principle:** build useful products, validate them in real conditions, and release only when they are ready.

## Portfolio

### AI Coop — AI-assisted development platform
A simple, versatile workbench for building, testing, debugging and shipping software and firmware with cooperating AI agents. The product direction spans Android, Windows, web and PWA development.

**Status:** Active development  
**Business model direction:** Useful local foundation with optional paid capabilities and hosted services.

### AI Coop Core — Robotics intelligence platform
A separate platform intended to provide shared intelligence for a fleet of non-humanoid robots: task planning, perception, memory, reusable skills, model integration and coordination.

Its first physical proving ground is an affordable workbench-scale yarn selection and handling robot for real small-business work. The hardware design remains under research; no final arm architecture has been selected.

**Status:** Architecture and first project documented; robotics development is staged.

### Anonyzer — Android privacy and network protection
An Android privacy-focused product ecosystem, including the primary Anonyzer app and supporting profile-management and security-assurance work.

**Status:** Private development; release readiness and security claims are evidence-driven.

### Autozer — NFC utility for Android
An Android application for preparing, writing, reading and verifying supported NFC tags, with a privacy-conscious local payload workflow.

Website: [autozer.app](https://autozer.app)

**Status:** Product development.

### UI — Visual interface for AI-assisted development
A local visual inspection and annotation tool that lets a human identify, protect, discuss or remove interface elements and share that context consistently with AI coding agents.

**Status:** Working private tool; scope is being developed.

### Autonoo — Automotive marketplace concept
An AI-assisted vehicle marketplace concept focused on making vehicle discovery and the buying/selling process clearer and more accessible.

**Status:** Product concept and research.

### BioMorse — Human-computer interaction research
An exploratory research concept for intentional, silent communication between a person and a computer, using measurable biological signals rather than spoken output.

**Status:** Early research concept; no validated protocol or product claim.

### Affordable robotics and desktop microfactory R&D
Longer-term research into accessible robot arms, manipulation systems, inspection tools and small-scale automated manufacturing. This work is organized under the robotics direction of AI Coop Core.

**Status:** Long-term R&D; staged around practical, measurable prototypes.

## Development and release policy

All product source code, implementation details and R&D repositories remain **private by default**.

- Products may be proprietary and closed-source, whether offered free of charge or commercially.
- A free product or module is not automatically open source.
- Public downloads are made only through deliberate, versioned releases after review.
- Any open-source release will have an explicit, selected open-source licence.
- Customer-facing terms for proprietary products will define permitted use, redistribution, modification, support and commercial rights.
- No project should be assumed publicly available, open source or release-ready merely because it appears in this portfolio.

This page is a high-level overview. It intentionally excludes private source code, internal architecture, security-sensitive implementation details, unreleased designs and confidential R&D material.

## Release philosophy

**Private by default. Public by decision. Released when ready.**
